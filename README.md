
## 다운로드

**[최신 설치기 바로 받기](https://github.com/Mino7406/ACI/releases/latest/download/ARCADE_Cobblemon_Installer.exe)**

이전 버전은 [Releases](https://github.com/Mino7406/ACI/releases)에 있습니다.

## 설치 방법

1. 마인크래프트 런처를 한 번 실행해 로그인한 뒤 **완전히 종료**합니다.
2. `ARCADE_Cobblemon_Installer.exe`를 실행합니다.
   "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보** → **실행**을 누릅니다(서명되지 않은 프로그램이라 뜨는 경고입니다).
3. [다음]을 눌러 옵션과 모드를 확인하고 마지막 페이지에서 **설치(I)** 를 누릅니다.
4. 런처에서 **ARCADE 코블몬** 프로필을 선택하고 플레이합니다. 멀티플레이 목록에 서버가 등록되어 있습니다.

업데이트도 새 설치기를 받아 같은 방법으로 다시 실행하면 됩니다.

**문제가 생기면**: 설치기를 다시 실행해 **초기화**에 체크하고 설치합니다. 그래도 안 되면 설치기의 **설치 로그 폴더 열기**에서 `club-installer.log`를 관리자에게 보내주세요.
